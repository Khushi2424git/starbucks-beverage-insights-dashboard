# ☕ Starbucks Beverage Insights Dashboard

## 📌 About the Project

I'm excited to share my Starbucks Dashboard project!

I created this dashboard to explore Starbucks beverage data and turn it into meaningful insights through interactive visualizations. The main idea was to understand different beverage categories, compare their nutritional values, and present the information in a simple and visually appealing way.

While working on this project, I focused on creating a clean dashboard layout with useful KPIs, interactive filters, and different types of charts to make the analysis easier to understand.

## 🎯 Dashboard Overview

The dashboard provides an overview of Starbucks beverages, including nutritional information, category distribution, caffeine levels, and global presence.

### 📊 Key Performance Indicators (KPIs)

- **Total Beverages:** 33
- **Average Sugar:** 32.90
- **Average Calories:** 193.78
- **Average Caffeine:** 81.69

### 📈 Visualizations Included

1. **Average Calories by Beverage Category** – Compares the average calorie content across different beverage categories.
2. **Starbucks Global Presence** – Displays Starbucks locations across different geographical regions.
3. **Beverage Category Distribution** – Shows the percentage contribution of each beverage category.
4. **Average Caffeine by Category** – Compares caffeine levels across different beverage categories.
5. **Top 5 Highest Caffeine Beverages** – Highlights beverages with the highest caffeine content.

### 🎛️ Interactive Filters

- Protein Range – Allows users to filter beverages based on protein values.
- Beverage Prep – Allows users to explore different beverage preparation types.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Interactive Slicers and Filters
- Charts and KPI Cards

## 🎨 Dashboard Design

I chose a Starbucks-inspired green and white colour palette to maintain brand consistency and give the dashboard a clean, professional appearance.

I also included beverage images and Starbucks branding elements to make the dashboard more engaging and visually attractive.
